# DIA Jewels Dubai

A responsive e-commerce storefront for DIA Jewels Dubai, built with React, Next.js/Vinext, TypeScript and Tailwind CSS.

## Features

- Luxury responsive storefront
- Product catalogue and category filtering
- Product quick view
- Shopping bag with live totals
- Checkout form ready for payment-gateway integration
- Bespoke jewellery, brand story and contact sections

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

> Live payment processing requires DIA's chosen payment gateway credentials.
